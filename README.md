# 🌟 Lingoo Educational App

**Lingoo** is an interactive, offline-first Android educational application series designed for the Egyptian primary school English curriculum (Grades 2 through 6). It combines structured lessons with engaging multimedia activities to make learning English fun, accessible, and effective for young learners.

## 📖 Overview

The **Lingoo** series (`lingoog2`, `lingoog3`, and Grades 4–6 editions) provides students, parents, and teachers with a complete digital companion for primary English education. Built with an **offline-first architecture**, the app works seamlessly without an internet connection once installed.

---

## ✨ Key Features

- **📚 Interactive Textbooks:** Full curriculum-aligned units and lessons tailored to each grade level.
- **🔊 Native Audio Pronunciation:** Clear voiceovers for vocabulary, dialogues, and reading passages to build listening and speaking skills.
- **🃏 Smart Flashcards:** Visual vocabulary cards with audio support for quick memorization and review.
- **🎮 Educational Games & Quizzes:** Interactive exercises, matching games, and unit quizzes to reinforce learning and track progress.
- **🎨 Digital Coloring Pages:** Curriculum-themed coloring activities to keep younger learners engaged creatively.
- **📶 100% Offline Access:** All lessons, audio files, and activities are stored locally—no internet connection required during study.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Local Storage:** SQLite (Offline-First)
- **IDE:** Android Studio
- **Distribution:** GitHub Releases & Suhail App Store

## 🚀 Installation

1. Go to the **[Releases](../../releases)** section of this repository.
2. Download the latest `.apk` file for your target grade.
3. Enable **Install from Unknown Sources** on your Android device if prompted.
4. Install and launch the app—no sign-in or internet connection is required to start learning.
